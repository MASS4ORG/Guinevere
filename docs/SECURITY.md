# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use this repository's **Security** tab and select **Report a vulnerability** to create a private security advisory. Include the affected version or commit, impact, reproduction steps or proof of concept, and any suggested mitigation.

If private reporting is unavailable, contact a repository maintainer privately through GitHub. Please allow time for triage and a fix before disclosing details publicly.
