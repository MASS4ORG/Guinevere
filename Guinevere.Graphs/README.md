# Guinevere.Graphs

`MASS4.Guinevere.Graphs` is a .NET 10 GUI package built on Guinevere core and the published `MASS4.Graph` 1.0.0 package. It has no Excalibur or engine dependency. The generic canvas consumes immutable view descriptions; `GraphDocumentView` adapts the real headless document and editor without implementing a parallel model.

Keep one `GraphCanvas` per surface and call `Draw` in both Guinevere passes. Supply `GraphElementView` descriptions through a domain adapter. Only visible descriptions build layout controls; all descriptions remain available for logical navigation and accessibility. Bounds must conservatively enclose the complete node or edge ink, including curves. The package owns camera, selection, logical focus, and view metadata only. It never reads a payload or implements a graph document, registry, persistence format, or undo stack.

The element callback runs inside a stable, keyed, camera-transformed node. Draw in `gui.CurrentNode.Rect` or build child controls normally; text, hit tests, and nested controls inherit zoom. Screen transforms use viewport logical units, and display density belongs to the containing Guinevere viewport. World coordinates and camera calculations use doubles. `WorldToScreen`/`ScreenToWorld` include the last laid-out host transform; `Camera.WorldToView`/`ViewToWorld` use viewport-local units. An optional camera constructor argument configures zoom limits. Build and render use one descriptor and camera snapshot; resize or initial layout requests a settling frame.

Navigation: middle-drag pans; wheel zooms under the pointer; Ctrl+arrows pans; +/− zooms around the viewport center; 0 resets; Home frames all; F frames selection. Arrows move logical focus between nodes using world geometry. Enter enters a node's ports and starts/completes a connection; Tab/Shift+Tab cycles its ports; Escape cancels a connection or returns to the node. Space toggles view selection; Delete asks the adapter to delete the focused element. Tab leaves the surface when no ports are active; Escape returns from ports before leaving. Embedded input controls retain their own keyboard handling. The camera and `Navigation` methods are also directly callable by application commands.

Alt+arrows cycles logical links in adapter order so they can be inspected and deleted with the keyboard; Escape returns from a link to an available endpoint.

Set `Navigation.EditRequested` to execute requests through the real graph editor, and return its command result and diagnostics for announcements. An absent handler produces a validation announcement and changes no document. `Navigation.SearchRequested` opens a consumer-owned searchable command palette (Ctrl+K) or registry-backed creation palette (Insert/Shift+A); this package does not manufacture node registrations. Consumers must request a frame after out-of-band changes, as with other Guinevere state.

For real documents, create `GraphDocumentView(editor)` and call `Draw(gui)` in both passes. It builds labeled nodes and ports, cubic connectors, click/drag linking previews, curve selection and edit-adapter commands. `AddNode`, connection creation, Delete and undo/redo use that editor, including its compatibility strategy and validation rules. MG diagnostics remain available as structured `Diagnostics`; selection and connection events flow through the existing semantics bridge. `Palette(query)` searches `editor.Document.Registry.NodeTypes.Entries`, so generated registration remains transparent to the GUI.

Connections replace links occupying single-connection ports through one atomic `CompositeCommand`; a rejected replacement restores the original links and identities. Reconnecting identical endpoints succeeds without a mutation or history step. Set `AvoidReplacingConnections` to reject duplicates and occupied ports using the core diagnostics. Delete/Backspace on a focused port invokes `DisconnectPort`, removing all its attached links as one undoable command; the port remains intact.

Node payloads stay opaque. `NodeTitle` is an optional domain-owned presentation callback and is skipped for unknown node types. Default descriptions preserve unknown nodes and expose their error state. Positions are a separate view dictionary. GUI-owned layout commands participate in the real editor history alongside document commands but record no document changes: they never alter serialized metadata or invalidate evaluation. A group drag is one history step; keyboard nudges and `ResetLayout` are also undoable. Reset retains existing IDs, labels, ports, payloads, edges and earlier history. `SetPosition` supplies baseline metadata without recording a step. Initial positions can come from the document's optional layout metadata. `GraphConnector` supplies drawing, hit testing and conservative bounds for culling, including backward connections.

`Example-02-Graph` is the real arithmetic/dataflow playground; `Example-93-GraphCanvas` is the independent 10,000-tile benchmark. Running-flow observation overlays and organizer/domain scenarios remain subsequent acceptance work.

`IGraphSemanticsSink` extends `IControlSemanticsSink` with graph/node/port/edge roles, parent and connection relationships, names/types/errors, selection/focus, logical position/count, and virtualized state. Implement it alongside `IAccessibilityCapability` in a platform bridge and register that bridge normally. Plain control sinks receive stable scoped IDs, names, types/errors, transformed bounds, and visual state. No off-screen layout controls are required. Semantic events announce selection, focus, connection success/cancellation, and validation failures. Platform-native graph role mappings and edit-command adapters belong to their respective integration layers.
