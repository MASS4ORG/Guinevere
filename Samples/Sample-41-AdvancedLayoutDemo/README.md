# Sample-41-AdvancedLayoutDemo

This sample demonstrates how to build a complex, multi-panel dashboard application layout using Guinevere's layout system.

## Features
- **Header Bar**: Horizontal navigation with logo and navigation buttons.
- **Sidebar**: Vertical navigation panel with icons and labels.
- **Main Dashboard**:
    - Project cards with descriptions and animated progress bars.
    - Statistics panel.
    - Recent activity feed with accent indicators.
- **Footer**: Application status and copyright information.
- Use of `Expand()`, `AlignSelf()`, and `AlignContent()` for precise positioning.
- Custom drawing of UI components (Cards, Stats, Sidebar items).
