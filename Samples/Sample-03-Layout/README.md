# Sample-03-ChildrenLayout

This sample demonstrates advanced child alignment and distribution within nodes using `AlignContent` with separate horizontal and vertical controls.

## Features
- `AlignContent(float alignHorizontal, float alignVertical)`: Independently control how children are aligned within their parent container on both axes.
- Support for both `Axis.Horizontal` and `Axis.Vertical` layouts.
- Nested layout structures.
- Visualizing alignment results with multiple colored nodes.
