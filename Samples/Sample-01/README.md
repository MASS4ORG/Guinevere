# Sample-02-SimpleLayout

This sample demonstrates the basic layout capabilities of Guinevere, including:
- Absolute positioning of shapes (`gui.DrawRect`).
- Container nodes with `Axis.Horizontal` and `Axis.Vertical` directions.
- Margins and padding.
- Content alignment (`AlignContent`).
- Conditional rendering based on keyboard input.
- Hover and click interactions.
- Z-Index control.

## Controls
- **A Key**: Toggle a white rectangle in the layout.
- **Mouse Hover/Click**: Interact with the orange/red box.
