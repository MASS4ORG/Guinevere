# Sample-53-Menus

This sample demonstrates advanced menu systems in Guinevere, including multi-level menu bars, submenus, and context-sensitive flyout menus.

## Features
- **Menu Bar**: A standard application menu bar with multiple levels of nested submenus.
- **Context Menus**: Right-click triggered `Flyout` menus with specialized actions.
- **Theme Switching**: Real-time switching between Light and Dark modes.
- **Application Structure**: A realistic IDE-like layout with Sidebar, Content Area, and Status Bar.
- **State Management**: Handling menu-driven state changes like zoom, grid visibility, and status updates.
- **Keyboard Shortcuts**: Displaying accelerator hints (e.g., Ctrl+N, Alt+F4).

## Interaction
- Click menu items to execute actions.
- Hover over menus to open submenus.
- Right-click in the content area to open the context menu.
