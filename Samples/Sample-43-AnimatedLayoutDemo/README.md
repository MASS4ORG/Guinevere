# Sample-43-AnimatedLayoutDemo

This sample demonstrates how to create dynamic and animated layouts using Guinevere's layout parameters driven by time.

## Features
- **Animated Background**: A smooth color-cycling background driven by `gui.Time.Elapsed`.
- **Floating Panels**: Elements that move and scale using trigonometric functions (Sin/Cos) within the layout system.
- **HSV to RGB Conversion**: Utility for creating smooth color transitions and vibrant UI elements.
- **Dynamic Alignment**: Using `AlignSelf` and `AlignContent` with time-varying values to achieve physics-like movement.
