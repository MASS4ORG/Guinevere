# Sample-51-Buttons

This sample focuses on the `Button` and `IconButton` controls, demonstrating various styling options and edge cases.

## Features
- **Basic Buttons**: Auto-sized vs fixed-size buttons.
- **Colored Buttons**: Primary, success, warning, and danger themes using custom colors.
- **Styled Buttons**: Custom border radius (rounded/square) and font sizes.
- **Icon Buttons**: Using emoji characters as icons with background and hover effects.
- **Edge Cases**: Empty labels, extremely long text, and tiny button dimensions.
- **Interaction Tracking**: Real-time click counting and last-clicked status.
- Vulkan integration test case.
