# Sample-07-Scroll

This sample provides an in-depth demonstration of the scrolling capabilities in Guinevere, featuring multiple scroll scenarios.

## Demo Cases
- **Basic Scroll**: Standard vertical scrolling with a long list of items.
- **Nested Scroll**: Independent scroll areas within each other (side panels).
- **Mixed Content**: Scrolling complex items containing shapes, text, and interactive elements.
- **Programmatic Scroll**: Controlling scroll position via API (`SetScrollPercentage`, `ScrollToTop`, `ScrollToBottom`).
- **Performance Test**: Stress-testing the system with a large grid of scrollable items (10,000+ elements).

## Features
- `ScrollContainer()`: Convert a node into a scrollable area.
- `ScrollX` / `ScrollY`: Independent axis control.
- Programmatic scroll manipulation.
- Scrollbar interaction.
