# Sample-05-SingleNodeExpandMargin

This sample demonstrates how nodes expand to fill available space within a parent container and how margins affect their final layout.

## Features
- `Expand()`: Make a node grow to fill available space in its parent.
- `Margin()`: Define spacing around a node's content.
- Visualizing `OuterRect` vs `Rect`: Understanding how margins subtract from the outer bounds.
- Raylib integration test case.
