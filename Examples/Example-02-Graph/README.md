# Graph Playground

The graph-only interaction showcase. Run `dotnet run --project Examples/Example-02-Graph`. Example 93 remains the separate 10,000-tile scale benchmark.

The Sandbox is a real arithmetic dataflow document using the published `MASS4.Graph`, `MASS4.Graph.Dataflow` and `MASS4.Graph.Interpreter` packages, each pinned to exactly 1.0.0. The State machine adds the published `MASS4.Graph.State` at the same exact version. Number, Add, Multiply and Result types are registered through the actual registry API. The initial graph connects 2 and 3 to Multiply, then to Result; its executable behavior is covered by the headless dataflow test. The GUI reads no payload types; the sample's domain code formats constant values, draws a Number stepper in the node content slot, adds a "result" badge, and uses triangle output ports. The stepper changes the payload through the real editor, so every step is undoable.

Drag between port markers, or click one port and then another, to create a validated connection. Occupied single-connection ports replace their existing link atomically; reconnecting the same endpoints retains the existing edge without an alert or history step. Enable **Avoid replacing connections** to retain the core's duplicate/occupied-port diagnostics. Failed replacements restore the previous connections. Add node opens a searchable registry palette; Ctrl+K/Insert also opens it.

Delete/Backspace removes the focused node or connection. On a port marker, it disconnects all attached links as one undoable step; it never removes the port itself. Ctrl+Z/Ctrl+Y and the toolbar undo/redo document edits, node moves and layout reset in one chronological history through the real `GraphEditor`. A group drag is one step, regardless of its number of frames.

Click a node to replace selection. Ctrl+click toggles membership; dragging an already-selected node moves the group, while a completed plain click reduces it to that node. Arrows navigate and Shift+arrows move the selection. Reset layout restores each existing node's initial position, including subsequently added nodes; it never recreates or renames nodes, disconnects edges, changes payloads, or clears earlier history. Undoable layout commands update only the view dictionary, so they do not alter document layout metadata, emit document changes or invalidate evaluation.

The option row applies to the active scenario: **Minimap** shows or hides the minimap, **Style** cycles Blueprint, Paper and High contrast for every scenario, and **Links** cycles Bézier, straight and orthogonal routing. Each style is an application PSS file under `Styles/`; Blueprint adds link glow, Paper uses patterned ink strokes, and High contrast changes fonts, border widths, radii and port sizes. No graph palette or theme branch exists in code. Zooming out lowers the level of detail: port labels and node content disappear first, then ports and titles. Routing and LOD thresholds are behavior settings.

The playground header uses PSS and the embedded badge. Its tabs support Tab/Shift+Tab, Enter/Space, Left/Right, Home/End, focus indicators, and core accessibility semantics. The playground uses Guinevere.Styling without Excalibur, engine, or parallel graph-model dependencies.

Shift+click adds nodes or links, Ctrl+click toggles membership, and dragging empty canvas space selects intersecting nodes and crossing links. Ctrl+A selects all. Ctrl+C/X/V use the host clipboard for a selected subgraph, Ctrl+D duplicates it, and Alt+drag creates a duplicate move on release as one undo step. Escape cancels an active drag. **Edit actions** (also opened by right click) offers copying, cutting, pasting, duplicating, deleting, alignment, distribution and grid snapping. Clipboard paste remaps topology IDs and rejects content the published insertion API cannot preserve, with diagnostics rather than data loss.

**Copy JSON** exports the entire authored document and current positions to the clipboard; **Load JSON** loads clipboard JSON through core serializers and registry migrations, replaces the editor only on success, and reports unknown-node or migration diagnostics. Unknown payloads, ports and extension data survive saving. The running flow rebinds to a loaded document after any previous observation completes. Applications can use `Serialize(false)`, `SerializeLayout` and `SerializeViewState` for topology-only assets, a layout sidecar and a camera sidecar respectively; transient selection/hover state is omitted. Groups and collapsed containers still await the published core group model.

Each graph issue extends its scenario as part of acceptance:

- **Sandbox:** #84 PSS node cards, badges, validation, port shapes, routing and LOD; #85 selection, linking, clipboard, arrangement and semantic history; #86 deterministic persistence and unknown-content preservation against the published contracts.
- **Running flow:** a separate arithmetic document recompiled with the reference interpreter after each change. Evaluation and `ICompiledGraph.Observe` run off the UI thread, and `GraphFlowOverlay` draws moving pulses on active links and the observed value of every output. Edit numbers or links to watch the results update; compile diagnostics mark the affected nodes and links, and evaluation failures are reported under the canvas.
- **State machine:** #224 uses State's entry/state/transition contracts for Patrol ⇄ Chase and a Chase self-transition. Transition nodes expose typed triggers from `GraphTypeRegistry.Signals`; the picker cycles registered identities and never accepts event strings. Focus a transition or one of its ports/edges to inspect and assign/clear its trigger. Add state/transition, linking, deletion, undo/redo and JSON loading all use the real editor and State validation. **Rename + reload** resolves the saved “See player” identity to “Target spotted” through the registry rename API. The domain's named-state serializer, trigger presentation and loop routing live in the sample adapter.
- **Organizers:** Graph #12 and Guinevere #86 supply groups, notes, and collapsed containers, keeping view state separate from document semantics.
- **Domain scenarios:** #88 adds the shader adapter using real domain contracts.
- **Excalibur Controls:** a later, deliberate optional-styling mirror. The graph-only scenarios remain consumable without Excalibur.

The State machine compiles one authored asset for 1,000 separate interpreter instances. **Previous/Next instance** chooses the live inspector; **Send to instance** addresses only that instance, **Run/Pause** controls continuous evaluation, and **Step** advances one tick. The initial population splits between Patrol and Chase to make instance isolation visible. Active cards, population counts and accessibility state descriptions come exclusively from `ICompiledGraph.Observe`. Background ticks never overlap, and recompilation publishes a separate run so an old worker cannot replace the new snapshot. Compiler diagnostics and background failures appear in the editor. Ctrl+K/Insert opens a searchable registry creation palette.

`GraphPlayground.ShowPendingScenarios` adds the pending Organizers tab. A native accessibility bridge receives scenario controls and option-switch states through Guinevere core semantics and graph catalogs through `IGraphSemanticsSink`. `IGraphActionSource` requests focus, selection, connections, deletion, clipboard/history and search against the same editor; validation and selected-instance changes are announced with the graph ID.

Headless acceptance captures all three scenarios in each style. Set `MASS4_GRAPH_CAPTURE_DIR` while running `GraphStyleTests.ApplicationSheetsDrawBothScenariosAndCanBeCaptured` for the six dataflow PNGs and `FsmSceneTests.FsmScenarioRendersBothLoopsAndCanCaptureEachPssStyle` for the three FSM PNGs. Compilation of the live document remains on the UI thread; evaluation and observation stay in the background. Immutable-snapshot compilation is a future response to demonstrated compile jank.
